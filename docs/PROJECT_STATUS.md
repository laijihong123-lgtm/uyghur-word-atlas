# Uyghur Word Atlas

This repository is planned as a Uyghur adaptation of the open source [Word Atlas](https://github.com/designfuchen/word-atlas).

- Use original project code, not a lookalike recreation.
- Uyghur words enter quizzes only after language checking; no unverified bulk machine translation.
- Until verified Uyghur audio is available, no English voice fallback and no listening quizzes.
- Current status: adaptation and build pending verification.

Original code is MIT licensed; original media and data are subject to their own attribution and license terms.
