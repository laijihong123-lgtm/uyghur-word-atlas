# 维语词光 · 教材逐条复核正式词库版

网站：https://laijihong123-lgtm.github.io/uyghur-word-atlas/

本项目在 [designfuchen/word-atlas](https://github.com/designfuchen/word-atlas) 的原版开源 React / WebGL2 / FSRS 应用上改造，采用用户提供的 **《维吾尔语词表_逐条复核版.xlsx》** 作为学习词库。维吾尔文从右向左排版。

## 正式词库

- **1,817 条**教材「背诵词表」记录，全部保留维文、中文释义、教材页码和原始表序号
- **1,813 张**可学习词卡：4 组**同形异义词**合并为一张带多个释义的卡片，避免无语境歧义测验；原始义项仍完整保留
- **4 条**待确认词来自原文件「暂缓背诵」工作表，保存在 data/textbook_deferred.tsv，不进入词卡和测试
- 正式词库的唯一构建输入：data/textbook_reviewed.tsv；旧的 data/words.txt、data/counselor_focus_candidates.txt、tools/curate_2000.py 为历史研究文件，**不再用于正式网站**
- 参考原版的**由易到难的六阶段学习路线**，先根据人工挑选的常用基础词、中文词义的日常实用性、维吾尔文词形长度/词组复杂度、书面语与专有名词倾向建立估计难度，再在每组的小范围内穿插生活话题。六组不是按字母排序，也不是经语料库验证的词频榜，更不是官方 CEFR 认证。
- **18个可点击的自定进度学习关卡**：六阶段各3关，前17关各101词、最后一关96词；总共1,813词。每关按稳定词卡ID独立启动，可暂停继续；已学数量和掌握程度分别统计，旧词继续由FSRS间隔复习。不强制18个自然日学完。
- 主题归类根据中文释义关键词自动辅助生成，不是教材自带分类


## 书房与例句（2026-11-14）

- 主导航新增「书房」，包含**6 篇原创维语入门分级短文**、逐句中文、ULY 拉丁转写、可点亮生词查词卡、判断题与完成记录。
- **全部 1,813 张词卡都补至少一条例句**：沿用首批分级阅读关联的例句，并为其余词条补齐自动示例；维文、ULY 拉丁转写、中文和例句收藏都保留，在「书房 → 例句本」统一检索。构建会严格检查 1,813/1,813 张词卡的覆盖率。
- 「书房 → 生词本」支持收藏、学习中、到期复习、已掌握的筛选与查询，复用原来的 FSRS 进度与书签。
- **例句音频暂停**：已取消批量生成例句和阅读短文的语音，优先核对维文、词形和中文释义。单词原有 MP3 保留。
- 阅读完成记录和例句收藏保存于既有本地学习进度，随 JSON 学习备份导出恢复。**不更换 dataset ID，不清空既有进度**。
- **质量提示**：完整例句中的大量内容是按词性与语境模板自动生成的**学习草稿**，并非母语者逐句审校的地道用例。对于语法功能词与不宜直接变位的复杂词条，会明确标成「词形识别示例（非真实用法）」。不要将自动草稿视为权威维语教材或合格词典例句。例句暂不提供语音朗读；原单词音频保持不变。
- 本书房为开源版本上的维语入门阅读实现，不包含原作者在线版完整的 732 篇英语分级文章及《小王子》。

## 学习功能

保留原版每日学习、间隔复习（FSRS）、统计、收藏和 3D 星图。每日新词目标在既有 5/10/15/20/30 词基础上增加 **100 词**，新词按重新估计的学习路线排列；复习词另算。首次引导也改成六个实际维语阶段。词卡提供按 ULY (Uyghur Latin Yëziqi) 规则自动生成的拉丁转写（如 ئاپا → apa、مەكتەپ → mektep），可在网格、列表、详情页、练习题与搜索中使用。此转写并非国际音标（IPA），不代表真人核音；姓名与借词可能需要进一步校对。音频不用英语发音替代；已在 GitHub Pages 的严格构建中实现全部 **1,813/1,813** 张词卡的维吾尔语 AI 合成 MP3，必须全部生成、文件存在且通过抽样解码校验才能发布。实际音质尚未经母语者逐条听审。模型采用 Meta MMS Uyghur Arabic Script，许可 CC BY-NC 4.0，限非商业用途。对原表以 - 结尾的动词词干，保留教材标记但不强制考拼写连字符。

本次仅重新排列学习顺序，**保留原 1,813 张词卡的唯一 ID 及数据集 ID**，此前的学习记录、收藏和复习算法状态不应因排序变化而丢失；若已有未完成的学习旅程，可能需先完成它才进入新排序的后续旅程。开始组别仍由「我的」→「从哪个难度开始」决定。\n\n旧的 46 词候选版以及 2000 词候选版有不同 datasetId；新版学习记录使用独立命名空间，避免不同词义的历史复习进度被错配到教材词。

## 配图原则：优先复用原作者的插画

- 优先从 [Word Atlas 原版](https://github.com/designfuchen/word-atlas) 的 **CC BY 4.0** 插画库选图；允许中文释义完全相同、常见语法形式变化以及经过人工整理的近义词/相近概念匹配。
- **不采用无约束的字符串包含**，例如不能把“六十五”配成“六十”，不能把“长城”只按“墙”配图；尤其谨慎处理人名、地名和民族文化专有词汇。
- 能找到合理匹配的原版图，就优先保留它，不用自动绘制的场景替换；余下词条再以有中文义项标注的补充插画兜底，保证所有 1,813 张词卡都有图。
- `image-attributions.json` 记录原图来源、原英文词条、匹配中文义项以及匹配方式；`generated-image-attributions.json` 和 `fast-generated-illustrations.json` 分别记录补充图片来源。构建会检查三类配图覆盖完整且互不混淆。

## 构建与校验

GitHub Actions 自动克隆原版源码、通过 tools/port_uyghur.py 导入词库、执行逐条保真校验、运行原版测试并编译两个版本：
- uyghur-atlas-website：GitHub Pages 子目录版本
- uyghur-atlas-netlify：适用于 Netlify Drop 的根目录版本

构建必须确认 1,817 行源记录、1,813 张词卡、所有源释义逐字一致、4 条暂缓词未被导入，否则自动失败。此程序依据用户提供的词表复核记录，不声称网站额外进行了母语专家逐项审校。
